## 1. Обзор проекта

### Назначение
- **StaticRustLauncher** - десктопное приложение-лаунчер для игры Rust
- Предоставляет интерфейс для управления игровыми серверами
- Обеспечивает автоматическое обновление игры через SFTP
- Отображает статистику серверов и новости

### Основные возможности
- ✅ Просмотр списка серверов с статистикой
- ✅ Автоматическая проверка обновлений игры
- ✅ Загрузка и установка обновлений через SFTP
- ✅ Система новостей
- ✅ Управление хостингом
- ✅ Настройки приложения
- ✅ Система авторизации

## 2. Архитектура приложения

### Паттерн проектирования: MVVM (Model-View-ViewModel)

```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│      View       │    │   ViewModel      │    │      Model      │
│   (XAML/Code)   │◄──►│  (Business Logic)│◄──►│  (Data Layer)   │
└─────────────────┘    └──────────────────┘    └─────────────────┘
```

### Принципы архитектуры:
- **Разделение ответственности** - UI отделен от бизнес-логики
- **Слабая связанность** - компоненты взаимодействуют через интерфейсы
- **Высокая тестируемость** - ViewModels можно тестировать независимо
- **Переиспользование** - базовые классы и интерфейсы

## 6. Ключевые компоненты

### 6.1 Базовые классы

**BaseViewModel** - базовый класс для всех ViewModels:
- Реализует INotifyPropertyChanged
- Предоставляет метод Set() для уведомления об изменениях
- Реализует IDisposable для освобождения ресурсов

**BaseCommand** - базовый класс для команд:
- Абстрактный класс для реализации команд MVVM
- LambdaCommand - конкретная реализация с лямбда-выражениями

### 6.2 Модели данных

**Server** - модель игрового сервера:
- Информация о сервере (название, карта, игроки)
- Статус сервера (premium, vip)
- Ссылки на социальные сети

**NewsItem** - модель новости:
- Заголовок, описание, дата
- Изображения и ссылки

**SettingsApp** - настройки приложения:
- Пути к файлам игры
- SFTP настройки
- Языковые настройки

### 6.3 Сервисы

**UpdateService** - сервис обновлений:
- Загрузка файлов через SFTP
- Проверка целостности файлов (MD5)
- Отслеживание прогресса загрузки
- Повторные попытки при ошибках

**ServerService** - сервис серверов:
- Получение списка серверов через HTTP API
- Фильтрация и сортировка
