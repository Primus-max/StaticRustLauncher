# Диаграммы зависимостей StaticRustLauncher

## 1. Общая архитектура приложения

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           PRESENTATION LAYER                                │
├─────────────────────────────────────────────────────────────────────────────┤
│  MainWindow.xaml  │  HomePage.xaml  │  NewsPage.xaml  │  SettingsPage.xaml │
│  MainWindow.xaml.cs│ HomePage.xaml.cs│ NewsPage.xaml.cs│SettingsPage.xaml.cs│
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                           VIEWMODEL LAYER                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│ MainViewModel │ HomeViewModel │ NewsViewModel │ HostsViewModel │SettingsVM   │
│ LoginViewModel│PlayNowViewModel│ServerDetailVM │NewsDetailWindowVM│          │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                            SERVICE LAYER                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│ UpdateService │ ServerService │ NewsService │ HostingService │UpdateChecker│
│ SFTPClient    │ EventBus      │ Logger      │                │             │

                                    │
                                    ▼
```

## 3. Иерархия сервисов

```
IDataService<T>
    │
    └── DataService<T> (HttpClient)
        │
        ├── ServerService
        │   └── GetDataAsync("http://localhost:5208/api/servers")
        │
        ├── NewsService
        │   └── GetDataAsync("http://localhost:5208/api/news")
        │
        └── HostingService
            └── GetDataAsync("http://localhost:5208/api/hostings")

IGenericService<T>
    │
    └── GenericService<T>

UpdateService
    ├── SFTPClient
    ├── MD5 Hash Verification
    ├── Progress Tracking
    └── Retry Logic

UpdateCheckerService
    ├── Version Comparison
    ├── Auto Check Timer
    └── Event Notifications
```

## 9. Поток данных в приложении

```
1. App Startup
   ├── Load Settings
   ├── Configure Services
   ├── Setup Logging
   └── Initialize MainWindow

2. MainWindow Initialization
   ├── Create MainViewModel
   ├── Setup Navigation
   ├── Load Initial Data
   └── Start Update Checker

3. Data Flow
   ├── User Action → View
   ├── View → ViewModel (Command)
   ├── ViewModel → Service
   ├── Service → Data Layer
   └── Data Layer → Service → ViewModel → View

4. Update Process
   ├── UpdateCheckerService → Check Version
   ├── EventBus → Notify Update Available
   ├── MainViewModel → Show Update Panel
   ├── User Action → Start Download
   ├── UpdateService → SFTP Download
   ├── EventBus → Progress Updates
   └── EventBus → Download Complete
```
